# Problem Statement

The primary user is a graduate business career advisor supporting MSBA international students. The user needs to triage job opportunities into `high_fit`, `medium_fit`, `low_fit`, or `unclear` before deciding whether to forward, hold, or investigate a posting.

Today this work is manual. Advisors must read titles, locations, skills, schedule type, and authorization language across inconsistent postings. NLP can help by extracting and comparing role-fit signals, retrieving similar examples, and presenting a grounded recommendation.
